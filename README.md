# Análisis técnico y trading algorítmico

Del gráfico de velas al robot que opera solo: análisis técnico con sus fórmulas, sistemas de *trading*, *backtesting* y sus sesgos, tamaño de posición, y robots en MQL y Python con los controles que evitan un desastre. No es una recomendación de inversión.

**Ver en línea:** https://aaramirez.github.io/trading/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
